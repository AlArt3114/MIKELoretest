# Hammershot 絕對本體論

**狀態：** `[FINAL][CRITICAL]`

* **定義與動作：** 本文件是 Hammershot 的唯一運動本體論。所有聯邦賽事文字、轉播、社群、論壇、新聞、百科與資料摘要，均須先以本文件建立正確的器材、動作、場地與賽局圖像，再由正式規則書補足數值、罰則及例外。

* **範圍與界線：** 公開角色名、判決名、統計名與舊資料欄位的轉譯，以 `Hammershot_Public_Terminology_Protocol.md` 為唯一正式規範。本文若引用早期程式欄位，只能視為相容別名，不能取代公開術語。

## 一、不可逆的核心事實

1. Hammershot 的法定比賽物件是 **Type-45 碟盤（Disc）**。
2. 進攻者操作的是 **Hammer（氣錘槍／Hammer Gun）**。它是具有瞄具、板機、儲能或作動模組與直線接觸機構的持槍式機械裝置。「氣錘槍」是歷史沿用的器材類別名，不表示每一合法型號都只能採氣壓供能。
3. 氣錘槍在整個動作中保持持槍姿態，**不得被揮動、掄動或沿弧線加速**。
4. 碟盤獲得擊發動能的唯一來源，是板機釋放後，既有儲能或作動模組驅動接觸頭沿槍身軸線向前運動所產生的 **直線機械推力**。
5. 操作者的手臂與軀幹只負責承托、瞄準、控制後座及維持槍身軸線；人體旋轉、手臂速度及器材迴旋均不構成合法輸出功率。
6. 防守方及投擲方以手直接操作碟盤，不持有氣錘槍，也不得使用球棒、球拍或其他擊打工具。
7. Hammershot 與棒球自始並存。CPBL 不是 CPHL、THCL、IHA、CL、FFA 或 Hammershot 的前身。

* **定義與動作：** 只要描述中出現「人物以手臂帶動器材沿弧線揮擊」，該描述便不可能是 Hammershot 的合法動作。

## 一之一、Hammer 的器材家族與字形

1. **原型不是單一製式。**《Unreal Tournament 99》的 **Impact Hammer** 可以用來理解「先儲存能量，再由直線機構瞬間推出接觸頭」的基本原理，但它不是法定外型、唯一動力來源或必須照抄的產品藍圖。只要遵守本文件的動作鏈、軸向撞擊與賽事輸出限制，Hammer 的實作可以有大量差異。
2. **可變實作。** 氣壓、彈簧、電磁、機械儲能及其他經認證的直線推進結構均可形成不同 Hammer 家族；品牌可以自行設計槍身、供能、瞄具、活塞行程與後座控制，但不得把器材改成可揮動的棒、拍或槌。
3. **Coffman hammer。** Armalite 曾以 AR-15 槍身為基礎，利用空包彈提供工作能量，製成稱為 **Coffman hammer** 的特殊實作。它仍須以封閉的直線機構接觸碟盤，不得把空包彈或槍身類比成發射彈丸。由於其供能及槍械外觀，該型在 Connecticut（CT）等共四個美國州屬違法器材；另外三州未經法規權威檔確認前不得自行點名。地方違法不等於所有 Hammer 均屬槍械。
4. **重量範圍。** Hammer 的整備重量可由約 **500 g 至 15 kg**。重量不是出力等級，也不直接授予較遠的擊發距離；在同一法定輸出下，它主要改變操作者承受及控制後座的方式。較輕型容易攜行、瞄準與卸武，但反向加速度與體感後座更明顯；較重型較能以質量吸收反作用，卻增加承托、轉向及送入 Drop Pad 的負擔。
   **成對認證例外：** 兩支不可拆分使用、由同一認證編號鎖定的雙持 Hammer，得以整組整備重量核對 500 g 下限。神崎はるか的雙手電動型為左、右各 250 g，整組 500 g；任何一支單獨使用均不具比賽資格。每支仍須分別通過接觸頭、浮球、輸出、電氣與卸武檢查，整組認證不得掩蓋單支失效。單支器材及非成對認證組合仍依原重量範圍審查。型式與狀態見 `Hammer_Homologation_Register_2046.md`。
5. **正式中文名。** Hammershot 的正式中文名稱為 **錘擊**，使用金字旁的「錘」。這個字形反映合法 Hammer 不採木製接觸器材。木字旁的「槌擊」不得作為正式名稱；舊資料中的「鎚擊」視為歷史字形，正規化輸出一律寫作「錘擊」。

## 一之三、IFAST與CAPS

* **系統與功能：** 2030年後，正式賽事容許經核准的IFAST（InField AI System for Tactical use）合法穿戴式戰術系統。CAPS（Computer Assisted Placement System／電腦輔助配球系統）是IFAST的子系統，用於輔助投擲員、捕接員及教練安排配球與落點。

* **系統與功能：** 兩者只提供資訊與建議，不替選手投出Type-45、不接管Hammer擊發，也不改變投、打、走、守的責任主體。完整市場與至少11家供應體系依`Hammershot_CAPS_IFAST_Ecosystem.md`。

## 一之二、曲面接觸頭硬鎖

1. Hammer 活塞在板機釋放後向前彈出的末端稱為 **接觸頭（Impact Head）**。
2. 聯盟禁止平頭、平板或可形成大面積同時接觸的 Impact Head。法定接觸頭必須具有可辨識的 **曲面**；未經量測合格不得進入正式比賽。
3. 曲面限制使有效甜蜜點小於平面接觸設計。ADS 即使大致對準，時機、軸線或碟盤姿態稍有偏差，仍可能形成擦切、偏轉、低效率撞擊或完全未接觸的 Whiff。
4. 因此 Hammershot 的打擊率不會因機械出力穩定就自然升高。聯盟標準化的是最大輸出，不是接觸成功率；曲面接觸頭所要求的動態視力、時機及精確軸線，是整體打擊率受到抑制的主要原因之一。
5. 不得自行補造曲率半徑、接觸面積、材質硬度或各聯盟的容許公差；這些數值必須由正式器材規章或當場檢測資料提供。
6. 每支通過型式認證的 Hammer 均裝有接觸頭浮球指示。只要接觸頭伸出，浮球即升起供裁判辨識；其訊號與力量大小無關，也不單獨證明接觸碟盤或形成活碟盤。成對認證器材的兩支須分別顯示與驗機。

## 二、唯一合法的擊發動作鏈

* **設定與沿革：** 法定順序固定如下：

* **定義與動作：** `Carry → Draw/ADS → Charge → Fire/Release → Linear Piston Impact → Disposal → Skate`

1. **Carry（持槍）**：單支型由雙手持槍；成對認證雙持型由兩手各持一支。解除保險後，器材維持待發姿態。
2. **Draw/ADS（舉槍／預瞄）**：以槍托抵肩、合法腰射或該型號核准的雙持姿勢，使待擊發接觸頭的軸線對準預測接觸點。
3. **Charge（儲能／待發）**：扣住板機，啟動該型 Hammer 的法定儲能或作動準備程序並鎖定；氣壓型由泵體壓縮，其他型號依其認證機構完成待發。
4. **Fire/Release（釋放擊發）**：在碟盤進入甜蜜點時鬆開板機，以負緣觸發釋放活塞。
5. **Linear Piston Impact（直線活塞撞擊）**：活塞沿槍身軸線向前運動並接觸碟盤；沒有橫向掃擊或弧線器材運動。
6. **Disposal（卸武）**：完成擊發後，利用反作用力將氣錘槍安全送入打擊區兩側的 Drop Pad。
7. **Skate（滑行）**：雙手淨空後，進攻者才以直排輪進入跑壘與推進階段。

* **範圍與界線：** `Draw/ADS` 與 `Charge` 的戰術節奏可以因選手與 Hammer 型號而異，但順序不得倒置；任何 `Charge → ADS → 揮擊`、以身體轉矩增加輸出或擊發後仍持槍滑行的描述均屬錯誤。

## 三、卸武與移動硬鎖

1. 擊發員在離開本壘圓前必須完成卸武並使雙手淨空；仍持有氣錘槍者構成妨礙守備。
2. 氣錘槍應落入 Drop Pad。未落入而彈回跑壘路徑者，成為合法場地障礙與 Trip Hazard；不得把它寫成憑空消失或由工作人員即時拾走。
3. 投擲員（P）與捕接員（C）穿著 Grip Shoes；其餘場上野手、擊發後跑者穿著 Inline Skates。
4. **穿著直排輪不得執行投擲動作。** 位置轉換必須經裝備暫停更換履具。
5. 擊發階段使用氣錘槍；手動投擲階段使用碟盤。兩者的器材、動作與發力來源不得混寫。

## 四、Type-45 碟盤

1. 法定比賽物件為直徑 **120 mm** 的 Type-45 雙層中空碟盤。
2. 上下兩片圓盤由中央支柱連接，中間保留 **0.5 cm Air Gap**，以維持陀螺穩定與空氣動力特性。
3. 三層複合結構為：
   - **Core**：熱固形塑膠，承受活塞衝擊並維持形狀。
   - **Mid**：微氣室，吸收衝擊並協助能量轉換。
   - **Skin**：軟橡膠外層，供手動投擲施加上旋或側旋，並降低接捕傷害。
4. 碟盤落地後受雙輪效應影響，傾向高速直線滾動，而非產生不可預測的球體彈跳。
5. 防守方以非對稱戰術手套接傳：接盤手負責吸收衝擊，傳盤手維持輕薄以控制旋轉與釋放角度。傳統網袋式棒球手套不屬於本運動。

## 五、投擲與接傳本體論

1. 投擲是 **手動投擲（Manual Throw）**：手指、手腕與手臂直接控制碟盤的 Spin Rate、Release Angle 與飛行路徑。
2. 投擲員不站在投手丘；場地沒有 Mound。合法位置與起始區域依 GHCS 及規則書判定。
3. 投擲員可以採用不同釋放高度、軌跡與旋轉風格，但不得將其描述為使用氣錘槍發射，也不得把擊發員描述為徒手把碟盤打出去。
4. 防守轉傳、遠距處決與回傳均以碟盤的手動接傳完成；使用 `throw`、`release`、`spin` 時，必須清楚標示主體是投擲方，而非氣錘槍擊發方。

## 五之一、手動投擲姿勢家族

* **定義與動作：** 投擲姿勢與碟路是兩個不同欄位：**姿勢家族**描述投擲員如何就位、移動與釋放；**碟路（Arsenal）**描述 Type-45 離手後的旋轉與飛行反應。同一名投擲員可以用一種基礎姿勢投出數種碟路，也可以在合規範圍內形成混合姿勢。

* **範圍與界線：** 所有姿勢均須遵守以下共同條件：投擲員穿著 Grip Shoes、以手直接操作 Type-45、在法定投擲區內完成釋放，並受起動時機、Pivot Foot、死球時間預算及其他正式規則約束。姿勢名稱只描述手動投擲，不得反向套用到氣錘槍擊發。

| 家族 | 合法機械圖像 | 主要戰術性質 |
| :--- | :--- | :--- |
| **High（高釋放）** | 以穩固下盤建立較高釋放點，手臂自上方完成碟盤釋放；不是站上投手丘，也不依賴丘面重力位能。 | 較陡的進入角與較清楚的垂直層次，但較容易被擊發員建立 ADS 參照。 |
| **Mid（側向釋放）** | 軀幹側向配置，使手臂從身體側面釋放碟盤。 | 強調橫向進入角、側旋與左右位移。正式文本不得直接套用棒球的左右打剋制公式，除非賽事資料另有證據。 |
| **Sub（低釋放）** | 降低重心，使碟盤在接近場面的高度離手；手背可以接近地面，但不得觸地拖行碟盤。 | 以低視角、升力錯覺及較晚出現在視野中的軌跡干擾 ADS。 |
| **Bowl（延臂旋轉）** | 以 Grip Shoes 合法助步，保持投擲臂延伸並以大圓周帶入手腕釋放；能量仍由人體手動投擲產生。 | 容易建立高 Spin Rate，適合 Doosra 等反向旋轉碟路；動作幅度大，起動較容易被觀察。 |
| **Windmill（風車式）** | 投擲臂沿垂直圓周運動，從較低位置完成手腕與手指釋放。 | 節奏快、釋放點特殊。`Softball` 只可用來說明訓練傳承，不是 Hammershot 的正式姿勢名稱。 |
| **Fix（定基座）** | 雙腳或 Pivot Foot 維持穩定，以軀幹、前臂、手腕與手指完成投擲，不以助跑增加變數。 | 重視重現性、Release Angle 與落點控制；不代表碟路必然筆直。 |
| **Run（助步釋放）** | 在法定投擲區內以 Grip Shoes 短距離助步，於合規 Pivot Foot 與釋放點完成手動投擲。 | 以移動中的釋放點干擾 ADS 並增加初速；不得寫成穿直排輪投擲或離開法定區域後拋出。 |

* **定義與動作：** 姿勢標籤不是封閉的階級，也不存在永久的「七派相剋表」。例如 `Fix/Bowl Hybrid` 只表示穩定基座結合延臂旋轉釋放；它不會自動產生特定球速、控球率或勝負結果。

## 五之二、碟路與 Arsenal 語義

* **範圍與界線：** 正式文字宜使用 **碟路、投擲路徑或 Arsenal**；「球種、球路、變化球」僅視為資料庫中的歷史簡稱，不得因此把 Type-45 改寫成球體。

| 碟路 | 合法語義 |
| :--- | :--- |
| **Doosra** | 以手指與手腕建立反向旋轉，使碟盤初始外觀與後段橫移方向不一致。 |
| **Cut** | 以偏置旋轉軸造成較短、較銳利的橫向切入。`Cutter` 為可接受的別稱，但比賽物件仍是碟盤。 |
| **Drift** | 讓碟盤在飛行中形成較長、較漸進的側向漂移。 |
| **Drop** | 透過旋轉、攻角與速度配置，使碟盤在末段呈現明顯下沉。 |
| **Heavy Drop** | Drop 的高負荷版本；末段下降更強，但不得描述為球體因縫線或球心產生的沉降。 |
| **Riser** | 以升力延後自然下降，使碟盤相對預測線呈現上浮或維持高度的視覺效果；不表示碟盤在無外力下違反重力向上加速。 |
| **Parachute** | 讓碟盤顯著失速並以較陡角度下降，重點是速度衰減與落點時間差。 |
| **Turbulence** | 利用旋轉軸、迎角及場地氣流交互作用形成不穩定漂移；若人物資料另有風場專長，才可寫成主動利用側風。 |
| **Low-spin／Knuckle** | 極低旋轉碟路，對細微氣流更敏感。`Knuckleball` 只可作歷史別稱，不得以球體縫線物理解釋。 |

* **名冊與身分：** `Velocity`、`Control`、Arsenal 等級與具體 Spin Rate 必須來自當季名冊、playerdata 或比賽 telemetry。來源未提供時，不得捏造 km/h、rpm、百分比、毫米誤差或「全聯盟第一」等精確敘述。

## 六、場地與空間本體論

1. 正式場地使用 **GHCS（Generic Hammershot Coordinate System）**。中軸為核心座標基準，不存在投手丘。
2. 標準場地寬 14 公尺、長 28 公尺；1 GU 等於 3.5 公尺。場地的具體節點、邊界及主場變體由 FENCES 與正式規則書管理。
3. 法定邊界包括：
   - **Goal Array**：複合式碟盤門陣列。
   - **Net**：下層網袋；依 Q-Lock 狀態判為死碟盤、自動壘打價值或界外。
   - **Crosswall**：橫樑區；接觸後碟盤仍為活碟盤，可能反彈回場內。
    - **Void**：上橫樑上空域；碟盤合法穿越時判為 **Field Goal（FG）**。早期引擎事件碼 `Home Run` 只作資料相容用途。
   - **Bounce Wall** 與 **Stands Net**：提供反彈或安全減速的場地邊界。
4. **Kill Zone** 位於本壘以外各實體壘包周圍。防守方可將碟盤不落地擲入感應區，對尚未取得安全狀態的跑者完成遠距處決；本壘不適用此方式。
5. 不得用「投手丘上空」「揮棒越過牆面」等其他運動的空間圖像替代 Axis、Goal Array、Crosswall、Void 與 Kill Zone。

## 七、場上角色與 Fluid Five

* **設定與沿革：** 單一 Half-Round 的標準場上防守編制為 **1P + 1C + 5F**，合計 7 人。

| 角色 | 主要裝備 | 合法核心行為 |
| :--- | :--- | :--- |
| P（投送員／Deliverer） | Type-45 碟盤、Grip Shoes、戰術手套 | 手動投送、接傳、控制旋轉與釋放角度 |
| C（捕接員） | Grip Shoes、可用雙手重裝戰術手套 | 捕接、近距離處理、轉傳與場上訊號 |
| 5F（五名野手） | Inline Skates、戰術手套 | 高速移動、接傳、封鎖空間、Kill Zone 處決 |
| 擊發員／Striker；擊發後為跑者 | 氣錘槍；擊發後改為雙手淨空與 Inline Skates | ADS、Charge、Fire/Release、Disposal、推進 |

* **範圍與界線：** 五名野手不是固定黏在五個位置上的靜態角色。投擲動作啟動前，他們可在合法界內區域自由移動，並可形成 3–2、4–1、5–0 或單一象限 Overload。此流動性不得被誤寫為棒球固定守位。

## 八、DC、Q-Lock 與防守框架

1. **Defense Coordinator（DC）** 位於場館制高點，透過合法通訊向捕接員、隊長或五名野手傳遞象限與座標指令；DC 不是場上第八名球員。
2. **Q-Lock** 於每個 Half-Round 開始前鎖定四個外野象限中的兩個；防守方宣告關閉象限，進攻方為其餘兩個開放象限指定 1B 與 3B 價值。
3. Q-Lock 是地形與價值協議，不是人物能力、槍械瞄準鎖定或得分倍率。
4. 常用防守框架可分為：
   - **Man-to-Man**：以人員追蹤與早期壓迫為核心。
   - **Contain**：壓縮推進通道、以 Gate Block 與空間控制限制高風險路徑。
   - **Zonal**：依 Q-Lock 與區域責任配置覆蓋，允許 Roaming 或 Overload。
5. 上述三者是戰術框架，不是固定相剋表。實際效果取決於人員、場地、Q-Lock、碟盤軌跡與臨場調度，不得把舊稿中的示例隊伍或人物當成永久規則。

## 九、正式賽事結構

1. 正式 Match 為 **四隊序列（Quad Sequence）**，由 A、B、C、D 四隊參與完整單循環。
2. 一場 Match 包含 6 盤（Sets）：A–B、C–D、A–C、B–D、A–D、B–C。每隊參與 3 盤。
3. **Set** 是兩隊之間的盤級對決；每個 Set 由 Round 組成，每個 Round 再分為先攻與後攻兩個 Half-Round。
4. 公開競賽層級固定為 **Match > Set > Round > Half-Round**。早期資料欄位 `Inning` 對外一律轉譯為 Round，不得以 Set 取代 Round，也不得將 Set、Match、Series 混稱。
5. 非正式 Skirmish 可以是 1 對 1 或三隊混戰，但不自動產生正式生涯紀錄、聯賽積分或 L-M 結算。
6. 單場登錄名單為 16 人，配置 8P 與 8F/C；單一 Half-Round 實際場上為 7 人，並受 2+2 性別硬鎖與 DNB 規則約束。具體換人、傷退與罰則以正式規則書為準。

## 十、進攻路徑與特殊狀態

1. 場上存在兩條不同的合法進攻路徑：
    - **Right Diamond**：依合法佔壘取得 Striker Merit，繞行並返回本壘時取得 Home Bonus。
   - **Left Gamble**：LB 不計分；抵達或越過 LT 時兌現 6 分並終止該跑者路徑。
2. 壘面完全淨空時，由火車頭在擊發前宣告路徑；已有跑者時，後續進攻者繼承已鎖定路徑。
3. **Fill-up**：防守方在未滿 6 個打席前先取得 3 個出局時，可折疊 Half-Round 或承擔風險繼續取得額外庫存獎勵。
4. **Fill-in**：6 名進攻者完成打席而未滿 3 出局時，符合資格的右側路徑英雄可進入抵死協議；左側豪賭得分者不具英雄資格。
5. `Fill-up` 與 `Fill-in` 是賽局狀態，不是一般形容詞，也不得互換。

## 十一、庫存、L-M 與結算語義

1. 每盤勝方取得的 **Inventory** 為勝方分數減敗方分數；敗方與和局的該盤庫存增加量為 0，單盤認列上限為 50。
2. Match 總庫存為該隊在三盤中的庫存總和。
3. **L-M Factor** 只根據該隊本場三盤戰績產生，且只用於本場 Match 排名：
   - 3 盤勝 0 敗：4.0×
   - 2 盤勝 1 盤和：3.0×
   - 2 盤勝 1 盤敗：2.0×
   - 1 盤勝 1 盤敗 1 盤和：1.5×
   - 1 盤勝 2 盤敗：1.0×
   - 0 盤勝：0.0×
4. `Match Score = Total Inventory × L-M Factor`。L-M 是賽後數學乘數，不是選手能力、武器輸出、球隊精神或可在場上「使用」的力量。
5. 年度加權戰績、個人統計與評議會特殊結算由相應正式規章管理；不得由舊稿中的推導公式補空。

## 十二、術語隔離硬鎖

### 禁止用來描述 Hammershot 動作

- 揮棒、揮擊、出棒、掄、甩棒、棒速、揮空、棒球式打擊、球棒軌跡。
- 把氣錘槍稱為球棒、槌棒、拍具或可揮動器材。
- 把碟盤稱為球，或用球體的彈跳、縫線與球心物理描述碟盤。
- 投手丘（Mound）及以丘面重力位能構成的投擲圖像。

### 公開術語硬鎖

- `Fire`、`Release`：氣錘槍板機釋放與擊發。
- `Impact`：直線活塞與碟盤接觸。
- `Whiff`：板機已釋放但活塞未接觸碟盤。
- `Good`：公開的有效投送判決；早期程式欄位 `Strike` 只能作相容別名，**絕不表示揮擊或擊發動作**。
- `Miss`：公開的無效投送判決；早期程式欄位 `Ball` 只能作相容別名。
- `Two-Good Against（2GA）`：兩次 Good 所形成的出局；取代公開用語中的 Strikeout。
- `Auto-Advance（AA）`：Miss 達門檻後的裁判授予推進；取代公開用語中的 Walk。
- `Body Advance（BA）`：投送碟盤接觸 Striker 身體後的授予推進與團隊 Extra；取代公開用語中的 Hit By Pitch。
- `Throw`、`Spin`、`Release Angle`：只描述投擲方或防守方的手動碟盤操作。
- `Field Goal（FG）`：碟盤穿越 Goal Array 的 Void 所形成之賽果；`HR`、`Home Run` 只可作早期資料欄位別名。
- `Catch Out` 與 `Kill-out`：分別表示合法接捕出局及 Kill Zone／封鎖出局；舊欄位 `Fly Out`、`Groundout`、`Force Out` 不得作公開主稱。
- `Runner Hit Home（RHI）` 與 `Average Merit Against（AMA）`：分別取代公開統計中的 RBI 與 ERA。AA、BA、Defensive Offside（DO）及 Double-Play Merit（DPM）不得產生個人 RHI；DO、BA、DPM 均屬團隊 Extras。

## 十四、最小正誤例

* **設定與沿革：** 錯誤：他把氣錘槍往後拉，扭腰揮擊，將球打過牆。

* **定義與動作：** 正確：他完成 ADS，扣住板機使 Hammer 進入待發；碟盤進入預測接觸點時，他鬆開板機，直線接觸頭擊發碟盤。碟盤穿越 Goal Array 的 Void，判為 Field Goal。

* **設定與沿革：** 錯誤：投手站上投手丘，用球路誘使打者揮空。

* **定義與動作：** 正確：Deliverer 穿著 Grip Shoes，以手指與手腕控制 Type-45 碟盤的旋轉及釋放角度；Striker 雖完成板機釋放，活塞仍未接觸碟盤，記為 Whiff，裁判再依規則判定是否構成 Good。

* **設定與沿革：** 錯誤：五名固定守位各自站好，等待球棒把球打進外野。

* **定義與動作：** 正確：DC 依 Q-Lock 下達座標，五名穿直排輪的野手向開放象限流動，準備攔截擊發後的 Type-45 碟盤。
